# ADR-010: Domain definitions, catalogs, levers, Tier-0 engine (M6)

- **Status:** Accepted
- **Requirements:** FR-DOM-01/02/03/10, FR-SEM-01/02, FR-SCG-01/09, AC-DOM-03, AC-SEM-01

## Decisions
- **Where `domain.yaml` lives.** Python plug-ins (Tier 1/2) ship it next to their
  module; `DomainPlugin.domain_definition()` loads it and refuses a mismatched
  `id`/`version`. Tier-0 domains are directories `<root>/<domain>/domain.yaml` with
  `tier: 0`, found on `$SIMCORE_DOMAIN_PATH` and in the installed `domains` package.
  A broken Tier-0 file is skipped and reported (`PluginRegistry.errors`,
  `simcore domains list`), never fatal for other domains.
- **Tier-0 engine.** `domains.process_network.plugin_for(definition)` (entry point
  `simcore.tier0:process_network`) builds one plug-in class per (id, version);
  instances pickle by definition so they work in the spawn worker pool. Semantics:
  station servers, full batches, blocking after service on full buffers (external
  arrivals always enter), changeover on item-type change, operator pools released
  at service end, MTBF/MTTR breakdowns that stop new starts, scenario
  overrides via `params.stations.<id>`.
- **Catalogs** = core catalog (`simcore.catalog.CORE_METRICS/CORE_DIMENSIONS`) merged
  with the domain's metrics/dimensions (domain ids override core ids). Metrics may
  use core dimensions without redeclaring them. The capability manifest adds
  policies, disruption types, entity types and the envelope (`CapabilityManifest`
  spec, schema exported).
- **Levers** are applied only through `apply_levers`: unknown lever, wrong type,
  out-of-bounds and invalid enum values are config errors listing what is allowed;
  values outside the calibrated envelope are flagged (`extrapolated`), not rejected
  (FR-SCG-09 labels results in M9).
- **Domain versions.** A scenario's `domain_version` with a different major version
  than the installed plug-in is a config error pointing to migration.
- **Packaging line** (BRD 9.1 default) is the Tier-0 reference: SKU campaigns
  (random interleaving with a 5-minute filler changeover starves the line; the
  baseline runs A then B).
