# ADR-011: Service layer architecture (M7)

- **Status:** Accepted
- **Requirements:** FR-API-01..09, FR-SCG-07/08, NFR-09/14/16, BRD 7.9, Q9/Q10/Q13

## Decisions
- **Stack.** FastAPI under `/api/v1` (OpenAPI at `/api/v1/openapi.json`), SQLite
  metadata store by default (Postgres via `SIMCORE_METADATA_URL=postgresql://...`),
  local artifact store by default (`s3://bucket/prefix` adapter). Job artifacts
  live under `jobs/<job_id>/<experiment_id>/` with the M2 experiment layout.
- **Jobs.** `submitted -> queued -> running -> completed | failed | cancelled`.
  Cache key = hash of the result-relevant spec fields, every alternative's config
  hash, engine version, domain name+version and mode. An identical submission
  returns the active job or a *new* job record marked `cached` that points at the
  original results (nothing re-runs). Benchmarks from completed replications feed
  the estimator (median wall/sim-second; defaults until history exists).
- **Brokers.** `inprocess` (threads, dev/tests, `SIMCORE_CPU_WORKERS`) and `redis`
  (sorted sets per pool, priorities, cancel flags; workers are
  `python -m services.workers --pool cpu|gpu` sharing the metadata/artifact
  stores). GPU pool jobs need GPU workers; submission fails clearly otherwise.
- **Confirmation gate (FR-SCG-07, Q13).** Above 10 alternatives, 10 replications or
  5 estimated minutes, submission needs the HMAC `confirmation_token` returned by
  `/experiments/estimate` (secret from `SIMCORE_SECRET`).
- **Quotas, cancellation, timeouts.** Max active jobs per workspace (429 beyond);
  cancellation via broker signal checked between replications; per-job wall
  timeout -> `failed` with reason.
- **Progress** streams over SSE (`/jobs/{id}/events`) by polling the job record, so
  it works the same with in-process and remote workers.
- **Auth (Q10).** Off by default (single-user dev). With `SIMCORE_AUTH=1`: scrypt
  password hashes, bearer tokens or Basic auth, workspace membership checked on
  every request (`X-Workspace`), all records scoped to a workspace.
- **Untrusted inputs.** Inline scenario bundles may not reference files outside
  the server's data/examples directories; artifact keys reject `..`.
- **Audit** records submissions (with outcome), finishes, cancellations, scenario
  and analysis saves. Mutating requests are rate limited per client.
- **Packaging (Q9).** `docker/Dockerfile` (API + CPU worker), `docker/Dockerfile.gpu`
  (Isaac Sim base), `docker-compose.yml` (api, worker-cpu, redis, optional gpu).
- **FR-API-08.** JSON Schemas are served at `/api/v1/schemas/{name}`; TypeScript
  types are generated from them in M11.
