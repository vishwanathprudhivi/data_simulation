# ADR-006: Experiment-layer choices (M2)

- **Status:** Accepted
- **Requirements:** FR-EXP-02..10, FR-IFC-03/04/06, NFR-08, BRD 7.5

## Decisions
- **Seeds.** With `crn: true` every alternative uses `(master_seed, replication)`.
  With `crn: false` each alternative's master seed is
  `sha256("<master_seed>:<variant_id>")[:4 bytes]`, so it is independent but still
  reproducible.
- **Reference alternative.** Comparisons are `variant - baseline`; when
  `include_baseline: false`, the first alternative is the reference.
- **Intervals.** Student-t on replication means; paired-t for CRN comparisons
  (only replications that succeeded in both alternatives are paired); Welch for
  independent comparisons. Every CRN comparison also reports the Welch
  half-width on the same data ("unpaired"), which shows CRN's effect in the
  report (AC-EXP-03).
- **Output layout.** `runs/<experiment>/<variant>/rep_NNN/...` (BRD 7.5's
  `<scenario>` level is the alternative id), plus `results.parquet` (long:
  variant, replication, metric, value + provenance), `runs.parquet` (status,
  seeds, hashes, errors), `summary.json`, `report.md`/`report.html`.
- **Parallelism.** `ProcessPoolExecutor` with the `spawn` start method (portable,
  no fork-with-threads hazards). Results are collected in submission order, so
  parallel and sequential runs produce identical outputs.
- **Timeouts.** A per-replication wall-clock budget checked by the engine every
  4,096 events; exceeding it raises `SimulationTimeoutError`. It can abort a run but
  never alter one.
- **Failures (NFR-08).** A replication that raises is retried `retries` times
  (default 0: simulations are deterministic, so retries mainly help with
  environment failures) and then recorded as failed; the experiment continues.
- **Fitting.** MLE with location fixed at 0 for positive families; ranked by AIC;
  KS (with p-value) and Anderson-Darling statistics and Q-Q points reported. An
  empirical percentile-grid spec is always offered as a fallback.
- **Warm-up.** Welch's moving average is the diagnostic plot. The automatic
  suggestion uses MSER on the cross-replication mean: rules of the form "settles
  inside a band" fired far too late on the autocorrelated M/M/3 queue signal
  (e.g. 950 s for a ~100 s transient).
- **Evaluator cache key.** `(config hash after params, seed, replications, engine
  version, domain name+version, mode)`; in memory plus optional JSON files.
- **Fidelity promotion** (`promote_top_k`) is accepted but produces a warning until
  the kinematic backend exists (M4). Latin hypercube designs raise a clear error
  (BRD stretch).
